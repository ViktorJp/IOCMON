v0.4.7    - (September 22, 2026)
          - PATCH: Added a formal script update menu under the configuration menu. This has been modeled after
            the TAILMON script update feature, allowing you to choose between the stable or beta track.
          - PATCH: Added a new shortcut key to the main UI that allows you to easily detach from the current
            Screen session using the command "/opt/sbin/screen -S ioclmon -X detach;;". No more having to use
            the CTRL-A+D key combo -- thanks @rung!
          - PATCH: Added another menu item under the configuration menu that allows for the optional install
            of Entware binaries that are being used in the script. This is optional, as the script was written
            to use a different method if they aren't found. Please note that if "screen" is not installed, the
            script will be unable to run in the background.

v0.4.3    - (September 21, 2026)
          - PATCH: Fixed the URL paths to the Github repository to prevent the autoupdate functionality from
            returning a 404 error, and overwriting the script with bogus garbage. (@JB_1366)
          - PATCH: Fixed a possible concurrency error that was duplicating efforts during a filesystem sweep
            and now using a pid lock file to ensure only 1 runs at a time. (@visortgw)
          - PATCH: Using the same pid lock file, now prevents a second script from running at the same time
            that could also be causing concurrency issues. (@visortgw)
          - PATCH: Improved the Filesystem Integrity scan by utilizing a different method of scanning each file
            across the filesystem, dramatically speeding things up while dropping the strain on the CPU during
            this process. (@XIII @Ripshod)

v0.4.0    - (September 14, 2026)
            Initial public release! IOCMON is a lightweight, always-on security-intelligence monitor for
            Asus-Merlin routers. It runs quietly in the background and watches your router from four different
            angles at once, correlating what it sees against public threat-intelligence feeds to catch signs of
            compromise early, before they become a real problem. HUGE thank you to @visortgw for his relentless
            testing of IOCMON, and putting it through its paces on his end. A lot of his excellent suggestions
            turned into a good bit of functionality that was added to IOCMON thanks to @visortgw!
